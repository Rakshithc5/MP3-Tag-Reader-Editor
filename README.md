# MP3 Tag Reader & Editor

A command-line application in **C** for viewing and modifying MP3 metadata, including ID3 tag fields.

## Features
- Read MP3 metadata
- View supported tag fields
- Edit supported metadata fields
- Work with binary file data

## Concepts Practised
- File handling and binary I/O
- Structures, pointers, and string processing
- Parsing and updating metadata
- Modular C programming

## Getting Started
Check the source files and any Makefile or build instructions in the repository for the correct compilation steps.

## Project Details
- **Language:** C
- **Environment:** Linux command line
- **Focus:** Binary file processing and metadata editing
